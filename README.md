# Sales & Revenue Analysis Dashboard

## Project Overview

This project is an interactive Power BI dashboard designed to analyze sales and revenue data. It helps track business performance through KPIs, charts, and filters.

## Tools Used

* Power BI Desktop
* Microsoft Excel

## Features

* Total Revenue KPI
* Total Quantity Sold KPI
* Revenue Trend Analysis
* Top Performing Products Analysis
* Revenue Distribution by Category
* Interactive Category and Product Filters

## Dashboard Visuals

* Revenue Card
* Quantity Sold Card
* Revenue Trend Line Chart
* Product Revenue Column Chart
* Category Revenue Pie Chart
* Slicers for Interactive Filtering

## Outcome

The dashboard provides valuable business insights by identifying top-performing products, monitoring revenue trends, and supporting data-driven decision-making.
